# ✦ Stardust · Cosmic Particle Field

An immersive, interactive static webpage that simulates a living starfield. Move your mouse to disturb the particles and watch them react like cosmic dust caught in a gentle nebula breeze.

---

## ✨ Features

- **Dynamic Particle System** – Hundreds of glowing particles drift slowly, each with its own color, size, and breathing rhythm.
- **Mouse Interaction** – The particles are repelled by your cursor and gently attracted toward it, creating a fluid, responsive cloud effect.
- **Visual Elegance** – Soft radial gradients, semi‑transparent connecting lines, and a deep‑space background with subtle nebula glows.
- **Adaptive Performance** – Particle count automatically adjusts to screen resolution, balancing visual quality and smoothness.
- **Fully Self‑Contained** – Single HTML file, no external dependencies or network requests.

---

## 🖥️ Demo

Open the `index.html` file in any modern browser (Chrome, Firefox, Safari, Edge).  
No server or build tools required.

---

## 🚀 How to Use

1. Download or clone this repository.
2. Double‑click `index.html` to launch the page.
3. Move your mouse (or finger, on touch devices) over the canvas to interact with the starfield.
4. Enjoy the serene, responsive particle animation.

---

## 🛠️ Built With

- **HTML5** – Page structure and canvas element.
- **CSS3** – Typography, gradients, and responsive layout.
- **Vanilla JavaScript** – Particle physics, rendering, and interaction handling (no libraries).
